# TaskFlowCLI 使用方法

コマンドラインでタスクを管理するアプリケーションです。タスクは1件につき1つのJSONファイルとして保存されます。

## 動作環境

- Java 17 以上
- 依存ライブラリ
  - `lib/gson-2.14.0.jar`
  - `org.eclipse.jdt.annotation_2.4.100.v20251017-1955.jar`

## 起動

Eclipseで開いている場合は、`src/main/Main.java` を Java アプリケーションとして実行します。

コマンドラインから実行する場合は、リポジトリのルートで次のようにコンパイルして起動します。

```bash
javac -d bin -cp "lib/gson-2.14.0.jar:org.eclipse.jdt.annotation_2.4.100.v20251017-1955.jar" $(find src -name '*.java')
```

```bash
java -cp "bin:lib/gson-2.14.0.jar" main.Main
```

起動すると保存済みのタスクを読み込み、`> ` のプロンプトでコマンドの入力を待ちます。

```text
> list
タスクはありません。
> 
```

## コマンド一覧

| コマンド | 説明 |
| --- | --- |
| `add` | タスクを登録する。タイトル、説明、期限、優先度、タグを対話的に入力する |
| `list` | タスクの一覧を表示する |
| `list --tag <タグ>` | 指定したタグを持つタスクだけを一覧表示する |
| `show <ID>` | 指定したIDのタスクの詳細を表示する |
| `edit <ID>` | 指定したIDのタスクを編集する。入力項目は `add` と同じ |
| `done <ID>` | 指定したIDのタスクを完了にする |
| `delete <ID>` | 指定したIDのタスクを削除する |
| `exit` | アプリケーションを終了する |

IDは登録時に自動で採番されます。

## タスクの登録・編集

`add` と `edit` では、次の順に項目を入力します。

```text
> add
タイトル: 牛乳を買う
説明: 帰りにスーパーへ寄る
期限 (YYYY-MM-DD、未入力で期限なし): 2026-09-30
優先度 (LOW/MEDIUM/HIGH): HIGH
タグ (カンマ区切りで複数指定可): 買い物, 家事
タスクを登録しました。
```

- **期限**: `YYYY-MM-DD` 形式で入力する。未入力のままEnterを押すと期限なしとして扱う。形式が不正な場合は再入力を求める
- **優先度**: `LOW` / `MEDIUM` / `HIGH`（大文字小文字は区別しない）または `低` / `中` / `高` を指定する。それ以外の場合は再入力を求める
- **タグ**: カンマ区切りで複数指定できる。空のタグと重複したタグは無視される

`edit` では入力したすべての項目で既存の内容を置き換えます。状態と作成日時は変更されません。

## 表示

### 一覧表示

1タスクを1行で、ID、状態、優先度、タイトル、期限の順に表示します。期限が未設定の場合は`期限: `のあとが空欄になります。

桁をそろえる表形式にすると、コンソールのフォントによって全角文字の幅が変わり表示が崩れるため、項目名を添えた1行表示にしています。

```text
> list
[1] 未着手 / 優先度: 高 / 牛乳を買う / 期限: 2026-09-30
[2] 完了 / 優先度: 中 / レポート提出 / 期限: 
```

### 詳細表示

```text
> show 1
ID: 1
タイトル: 牛乳を買う
説明: 帰りにスーパーへ寄る
状態: 未着手
優先度: 高
期限: 2026-09-30
タグ: 買い物, 家事
作成日時: 2026-09-24 14:11:12
完了日時: 
```

期限と完了日時が未設定の場合は空欄で表示されます。

## 状態と優先度

| 状態 | 表示 |
| --- | --- |
| `TODO` | 未着手 |
| `IN_PROGRESS` | 進行中 |
| `DONE` | 完了 |

| 優先度 | 表示 |
| --- | --- |
| `LOW` | 低 |
| `MEDIUM` | 中 |
| `HIGH` | 高 |

`done` で状態を完了にすると、完了日時が設定されます。

## データの保存先

タスクは起動したディレクトリ直下の `data/` に、タスクID単位のJSONファイル（`1.json` など）として保存されます。保存ディレクトリは登録時に自動で作成され、存在しない場合はタスク0件として起動します。

`data/` はGitの管理対象外です。

## エラーメッセージ

| 状況 | メッセージ |
| --- | --- |
| コマンド未入力 | コマンドが入力されていません。 |
| 未対応のコマンド | 不明なコマンドです。 |
| 未対応のオプション | 不明なオプションです。 |
| IDの指定漏れ | IDを指定してください。 |
| IDが数値でない | IDは数値で指定してください。 |
| `--tag` のタグ指定漏れ | タグを指定してください。 |
| 該当するタスクがない | ID \<ID\> のタスクは見つかりません。 |
| 保存に失敗した | ファイルの保存に失敗しました。 など |
| 削除に失敗した | ファイルの削除に失敗しました。 など |

起動時にタスクの読み込みへ失敗した場合は、エラーメッセージと対象のファイル名を表示して終了します。

```text
JSONの形式が不正です。
対象ファイル: 9.json
```

## 終了

`exit` を入力すると正常に終了します。標準入力が終了した場合も同様に終了します。
